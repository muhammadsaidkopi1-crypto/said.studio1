Sambungan: ujung kiri dan kanan disamakan supaya tidak ada garis di belakang. Atas & bawah: menghaluskan titik kutub yang sering berpusar pada gambar AI. Kabut memudarkan bagian bawah, Cermin memantulkan langit ke bawah. Hasil diterapkan otomatis saat slider dilepas.

Ultra ringan: 512px, JPG 75%, sphere ±2,3 ribu segitiga. Ringan: 1024px, JPG 85%, sphere ±4 ribu segitiga. HD: 2048px, JPG 100%, sphere ±9 ribu segitiga.

Langkah 2Unduh sisi

Sphere 360°: bola langit utuh dengan gambar panorama menempel apa adanya, tanpa sambungan kubus. Di Roblox Studio: Import 3D pilih SkySphere.obj, unggah SkySphere.jpg lewat Asset Manager, isi TextureID pada MeshPart, lalu atur Anchored aktif, CanCollide dan CastShadow nonaktif, dan Size sebesar area map.

Nama file mengikuti format Roblox: Rt, Lf, Up, Dn, Ft, Bk. Piksel tepi tiap sisi dibuat tepat menyambung dengan sisi di sebelahnya, jadi langit terlihat satu bola 360° mulus tanpa garis kotak di Roblox Studio.

      Langkah 2Optimasi Roblox

      Sudah teroptimasi otomatis untuk Roblox: sekitar 3 ribu segitiga, vertex digabung, tekstur 256px berukuran pangkat dua, tanpa bevel.

      Langkah 3Warna & bentuk

      Satu warna dan Silver memakai tekstur 8×8 piksel, paling ringan.

      Metal aktif otomatis setiap logo diubah, jadi logo memantulkan cahaya seperti logam. Makin kecil kekasaran, makin mengilap seperti cermin. Pilih Matte untuk tampilan biasa. Bevel membantu pantulan terlihat lebih hidup.

      Cara import ke Roblox Studio
      1. Pilih preset Ringan (atau Ultra), lalu pastikan status model berwarna aman.
      2. Unduh .glb (tekstur warna dan map metal sudah tertanam di dalamnya).
      3. Roblox Studio: Home, Import 3D, pilih file .glb, lalu Import.
      4. Kalau ukurannya terlalu besar atau kecil, ubah Size pada MeshPart.
      5. Pakai .obj? Roblox tidak membaca .mtl. Unggah logo.png dari ZIP lewat Asset Manager, lalu isi TextureID pada MeshPart. Untuk efek metal dari .obj, tambahkan SurfaceAppearance pada MeshPart, lalu isi ColorMap dengan logo.png, MetalnessMap dengan logo_metalness.png, dan RoughnessMap dengan logo_roughness.png (unggah ketiganya lewat Asset Manager).
      6. Batas aman: di bawah 20.000 segitiga. Makin kecil, makin ringan di game.
      7. Biar makin ringan di game: pada MeshPart nonaktifkan CanCollide, CanTouch, CanQuery dan CastShadow, set CollisionFidelity ke Box, dan aktifkan Anchored bila logo tidak bergerak.
      8. Pantulan logam di Roblox mengikuti langit dan pencahayaan game, jadi tampilannya bisa sedikit berbeda dari pratinjau.

      Unggah audio ke Roblox

      Unggah banyak lagu sekaligus ke Roblox tanpa perubahan. Atur nama tiap lagu, lalu salin Asset ID-nya setelah selesai.

      Server unggah belum diatur. Halaman ini tidak bisa memanggil Roblox langsung dari browser (diblokir CORS) dan API key tidak boleh ditaruh di halaman. Deploy audio-upload-worker.js ke Cloudflare Workers, lalu isi URL-nya pada AUDIO_ENDPOINT di script tab Audio. Sebelum itu, kamu tetap bisa menambah file dan mengecek ukuran serta durasinya.
      Tips mengunggah (3)
      1. Pakai akun alt untuk aset yang belum pasti lolos moderasi Roblox.
      2. Audio dimoderasi Roblox. Statusnya bisa pending beberapa menit sebelum Asset ID bisa dipakai di game.
      3. File diunggah apa adanya, tanpa mengubah speed atau pitch. Batas Roblox: sekitar 7 menit per lagu dan 20 MB per file. Kalau WAV atau FLAC ditolak, ubah dulu ke MP3 atau OGG.
